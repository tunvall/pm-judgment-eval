# Comparison worksheet

Fill this in after collecting all PM responses. For each existing rubric
criterion, note whether the PMs independently raised something equivalent.
Then note anything PMs raised that isn't in the rubric at all — that's the
more informative half of this exercise.

Overlap key: **Y** = at least 2 of the PMs named this or something clearly
equivalent, unprompted. **P** = one PM named it, or PMs gestured at it
without naming it precisely. **N** = no PM raised anything like it.
